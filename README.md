# Family Devotions for the Week

A weekly guide for family devotions at home, following the daily lectionary and the
readings of the Church Year (LCMS / *Lutheran Service Book*).

**The site is `index.html`.** It is a single self-contained page: open it and it shows
the current week automatically, opened to today's reading. No server, no build step,
no dependencies.

Each week includes:

- a simple ten-minute order of devotion, beginning with the Invocation
- the appointed daily readings for each day (LSB Daily Lectionary, p. 299)
- talk-about-it questions for younger and older children
- the memory verse and hymn of the week, with links to hear the tune
- Sunday's propers — Introit, Collect, Gradual, and readings
- a "Kids in the Divine Service" explanation of one part of the liturgy
- a printable two-page handout (in `handouts/`)
